# لحم بعجين البغدادي — Al-Baghdadi

موقع إلكتروني احترافي لمطعم **لحم بعجين البغدادي** في المجر الكبير — حي العسكري.

## المميزات

- 🎨 تصميم دافئ مشرق بألوان كريمية وذهبية برتقالية تفتح الشهية
- 🖼️ صور احترافية للأطباق في المنيو
- 🍕 منيو تفاعلي مع تبويبات (كلاسيكي، بالجبن، بالبيض، برگر)
- 💫 تأثيرات احترافية: 3D Tilt + أزرار مغناطيسية + reveal animations
- 📱 تصميم متجاوب بالكامل
- 💬 طلب مباشر عبر الواتساب من كل صنف
- 📍 خريطة الموقع التفاعلية
- ⭐ آراء العملاء (carousel)

## الأقسام

- الرئيسية (Hero)
- عن المطعم
- المنيو الكامل مع الأسعار
- لماذا نحن
- معرض الصور
- آراء الزبائن
- التواصل والموقع

## معلومات المطعم

- **العنوان:** المجر الكبير — حي العسكري — قرب عمار المضمد
- **التوصيل:** 07821 227 177
- **أوقات العمل:** يومياً من 4 مساءً حتى 1 بعد منتصف الليل

## الصور

الصور الحالية من Unsplash كحل مؤقت. لاستبدالها بصور حقيقية من المطعم، ضع ملفات الصور في المجلد واستبدل روابط `img src` في `index.html`.

## التشغيل محلياً

```bash
# افتح index.html في المتصفح مباشرة
# أو استخدم خادم محلي:
python -m http.server 8000
```

ثم افتح: `http://localhost:8000`
