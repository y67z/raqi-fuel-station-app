# لحم بعجين البغدادي — Al-Baghdadi Lahm Bi Ajeen

موقع إلكتروني احترافي لمطعم **لحم بعجين البغدادي** في المجر الكبير — حي العسكري.

## المميزات

- 🎨 تصميم احترافي بألوان بغدادية دافئة (نار + ذهب + خشب)
- 🍕 منيو تفاعلي مع تبويبات (كلاسيكي، بالجبن، بالبيض، برگر)
- 💫 تأثيرات زجاجية فاخرة + 3D Tilt + أزرار مغناطيسية
- 📱 تصميم متجاوب بالكامل (Mobile / Tablet / Desktop)
- 🔥 أنيميشن نار، دخان، ولمعان على الفرن
- 💬 طلب مباشر عبر الواتساب من كل صنف
- 📍 خريطة الموقع التفاعلية
- ⭐ معرض وآراء العملاء

## الأقسام

- الرئيسية (Hero)
- عن المطعم (About)
- المنيو الكامل مع الأسعار
- لماذا نحن (المميزات)
- معرض الصور
- آراء الزبائن
- التواصل والموقع
